# JsBot-Tellus

**基于 @SnowLuma/SDK 开发的 QQBot 框架**

## 部署

JsBot 目前采取直接源码部署

```bash
# 拉取源码
git clone https://github.com/JsBot-Dev/JsBot-Tellus
# 复制配置文件
cp bot.config.example.json bot.config.json
 # 填入具体配置 也可以使用 vim bot.config.json
nano bot.config.json
# 下载依赖
npm install
# 生产启动
npm run start
# npm run dev  开发启动（Watch模式）
```
